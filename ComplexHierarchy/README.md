# ComplexHierarchy

This is a model of 2 objects that each consists of many parts (basic geometric objects). One object is organized using groups, the other one is organized using parts and sub-parts. 
The 3D models where not optimized after export and therefore suffers from bad typology.

Goal of this example file is to check if and how the hierarchical information of a CAD files is preserved using FreeCADs export mechanics. 

The model was created in FreeCAD 1.1.1.
